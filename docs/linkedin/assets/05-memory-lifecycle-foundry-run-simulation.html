Do not merge these concepts

Four stores, four responsibilities

The technologies may share infrastructure, but their contracts remain different.

Agent memory

Selected reusable knowledge.

  • Preferences
  • Conversation summaries
  • Reusable procedures
Not authoritative business truth.

Workflow checkpoint

Resumable execution progress.

  • Current node
  • Pending approval
  • State needed to resume
Not proof that a side effect occurred.

Business system

Authoritative operational records.

  • Order and payment status
  • Recorded approval
  • Verified repair and audit trail
The source of current truth.

Model context

Temporary input for one decision.

  • Instructions
  • Selected state and memories
  • Recent tool results
A projection, not a durable store.
Memory suggests what may help. Business systems determine what is true. Policies and approvals determine what is allowed.

Vendor-neutral concepts versus Foundry implementation

Foundry implements important parts of the lifecycle, while the application retains the business and governance contract.

Concern Vendor-neutral concept Foundry implementation Application still owns
Short-term memory Thread history and working state Usually managed by the orchestration framework, not Foundry Memory State schema, checkpoints, and context selection
Long-term types Episodic, semantic/profile, procedural User profile, chat summary, procedural Mapping product terms to domain meaning
Write path Capture, extract, verify, consolidate, store Conversation update, LLM extraction, managed consolidation, memory items What is safe and authoritative enough to retain
Read path Scope, retrieve, rank, select, inject into context Memory search tool or search APIs Authorization and current-evidence checks
Maintenance Correct, supersede, expire, delete, audit Item CRUD, TTL, delete scope/store, remember/forget commands Compliance workflow, audit policy, and user experience
Isolation Partition memory by subject and access boundary scope partitions memories Authenticate and authorize access to that scope
Extraction is not verification.
A model can identify a candidate memory without proving it is true.
Consolidation is not authorization.
Merging memories cannot grant permission to perform an action.
Retrieval is not current truth.
Retrieved memory must be checked against authoritative evidence.
